Addon Development

New stones, skins, gauntlets and props without writing Java. It's all JSON in an addon pack or a mod.

What you can add#

Custom StonesThe gauntlet_stones format. Make any item fit in the Infinity Gauntlet and Cosmi-Rod, with its own color, glint, tooltip, head slot support and power.Gauntlet Skin FilesThe gauntlet_skins format: add an Infinity Gauntlet skin with one JSON file and its textures, including custom models, glow layers and replacement rules.Custom GauntletsThe gauntlets format: make an item or power from another mod work as an Infinity Gauntlet, with stones drawn on the player model.Ground ItemsThe ground_items format: make any item lie on the ground like the Infinity Stones, break open into other items, combine, or be drawn by a Palladium power.Ability OverlaysTheme any power or ability in Palladium's skill tree with a JSON file in a resource pack, mod or addon pack. Colors, frames, icons, backgrounds and window art.Ability & Condition ReferenceEvery ability type and condition the mod registers with Palladium, with their properties and defaults, for use in your own powers.
SystemFolderOne file per
Gauntlet stonesdata/infinity/gauntlet_stones/item that fits in the gauntlet
Gauntlet skinsdata/infinity/gauntlet_skins/skin
Custom gauntletsdata/infinity/gauntlets/item or power that acts as a gauntlet
Ground itemsdata/infinity/ground_items/item that lies on the ground like a stone
Ability overlaysassets/<namespace>/ability_overlays/power or ability themed in the skill tree (a resource, so it can go in a resource pack)
Palladium powersdata/<namespace>/palladium/powers/power, using the mod's ability types and conditions if you want

How these files are read#

  • They always go in the infinity namespace folder (data/infinity/…) of your pack or mod. The file name is the ID.
  • The mod reads them from every mod and every pack in the addonpacks folder. If two packs have a file with the same name, the higher priority pack wins, so an addon can replace one of the mod's own files.
  • File names starting with _ are skipped, which is handy for templates and switched off files.
  • They're only read when the game starts, so restart after changing them. /reload won't pick them up.
  • A bad value falls back to its default and a broken file is skipped. Either way it gets logged once (Gauntlet stone <id>: …, Gauntlet skin …, Custom gauntlet …, Ground item …), so check logs/latest.log if something doesn't show up.

Making an addon pack#

Infinity Stone Core is a Palladium addon itself, and its content uses Palladium's addon pack format. The easiest way to add to it is your own addon pack: a folder (or zip) in .minecraft/addonpacks/ with data, assets and Palladium's addon/ folder for new items and blocks. The pack format itself is covered in Palladium's documentation.

A pack that adds a stone
addonpacks/chaos_stone_pack/
├── pack.mcmeta
├── addon/example/items/chaos_stone.json                 the item (a Palladium addon item)
├── assets/example/models/item/chaos_stone.json          {"parent": "infinity:item/infinity_stone"}
├── assets/example/lang/en_us.json
├── data/example/palladium/powers/chaos_stone.json       the stone's power and abilities
├── data/infinity/gauntlet_stones/chaos_stone.json       makes it fit in the gauntlet
└── data/infinity/ground_items/chaos_stone.json          optional, makes it lie on the ground like a stone

The same files work in a normal mod's src/main/resources.

Using the mod's powers#

  • The stone powers are infinity:power_stone, infinity:space_stone, infinity:reality_stone, infinity:soul_stone, infinity:time_stone and infinity:mind_stone. The gauntlet's is infinity:infinity_gauntlet. Check for them with palladium:has_power.
  • To check what's in a gauntlet use infinity:gauntlet_slot. To check whether a stone is available at all use infinity:stone_equipped. Every condition and ability type is on the reference page.
  • To give your own power the generated skin abilities, add an entry {"infinity:generate": "gauntlet_skins"} to its abilities, like the gauntlet power does. When it loads, that entry is swapped for every skin's apply ability and tree entry.
  • Scoreboard objectives you can read in conditions and energy bars: DamageCycle (power level), SoulStorage (souls), and tickrateCycle and timestonesidebar (Time Stone step). The old power_stone to mind_stone objectives for stones in the gauntlet are gone in 8.0: use infinity:gauntlet_slot instead.
  • To let players switch part of your power off, add an infinity:toggle ability and check its setting with the infinity:setting condition, like the stones' passive toggles.

In-game reference#

When Palladium generates its documentation (into mods/documentation/), the mod adds its own pages under infinity/: gauntlet_stones.html, gauntlet_skins.html, custom_gauntlets.html, ground_items.html and ability_overlays.html. Its ability and condition types go into Palladium's own pages. They're generated from the code, so they always match the version you have.

Real examples#

  • Pugmeowla's Infintrix turns four Omnitrixes into power gauntlets with gloves (custom gauntlets).
  • Infinity Protocol makes the Iron Man MK85 suit an item gauntlet whose stones only show during its nano gauntlet animation.
  • The mod's own data/infinity/gauntlet_skins, gauntlet_stones and ground_items folders are good to copy from.
