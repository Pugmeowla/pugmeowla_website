Custom Gauntlets

Turn an Omnitrix, an Iron Man suit or any glove into an Infinity Gauntlet with one JSON file, without the other mod knowing.

How it works#

Each custom gauntlet is a file in data/infinity/gauntlets/; the file name is its ID. You describe what counts as wearing it, where each stone is drawn, and optional extras. While a player wears it, everything works like the real gauntlet:

WhatHow
Stone menuThe Open Gauntlet key (G) opens it for the gauntlet in your main hand, otherwise the worn one, so gauntlets that are never held still work.
StonesAll six, and custom stones, fit; no duplicates. Item gauntlets store them on the item (they stay with it); power gauntlets store them on the player per gauntlet ID (they come back when it's put on again).
AbilitiesWith at least one stone inserted, the player gets infinity:infinity_gauntlet, so stones are used and snapped exactly as with the real gauntlet.
LookThe other mod draws its object as usual. With a stone inserted, the optional render_layer (e.g. a glove) is drawn on top, and each stone as a small stone cube on a bone of the player model, following that arm's animation.

An Infinity Gauntlet in the off hand or Curios hands slot takes priority, then custom gauntlets in file name order.

Worked example#

A glove from examplemod, worn in the Curios hands slot or off hand, with the stones on its knuckles. These six positions are the Infinity Gauntlet's own sockets, a good start for anything on the left hand.

data/infinity/gauntlets/power_glove.json
{
  "name": "Power Glove",
  "equipment": { "item": "examplemod:power_glove", "slots": ["curios:hands", "offhand"] },
  "slots": [
    { "origin": [7.65, 11.75, -1.15] },
    { "origin": [7.65, 13.25, -0.55] },
    { "origin": [7.65, 11.75, 0.15] },
    { "origin": [7.65, 11.75, -2.35] },
    { "origin": [4.55, 12.15, -2.65], "size": [0.9, 0.9, 0.9] },
    { "origin": [7.65, 11.75, 1.45] }
  ],
  "slim_offset": [-1, 0, 0]
}

Equipment#

FormWorn whenStones are kept
{"item": "<id>", "slots": [...]}That item is in one of the slots: mainhand, offhand, head, chest, legs, feet, curios:<slot>, trinkets:<group/slot>. Without slots: main hand and off hand.On that item
{"power": "<id>"}The player has that power, e.g. a coupled Omnitrix (the item becomes a power while worn).On the player, per gauntlet

Fields#

KeyDefaultMeaning
nameInfinity GauntletTitle of the stone menu (text component).
equipmentrequiredSee above.
slots[]Up to six placements, by menu slot (the six stones' own slots are Space, Mind, Reality, Power, Time, Soul). null leaves a slot undrawn; a stone in it still works.
slim_offset[0, 0, 0]Added to every origin for slim-armed players, usually [-1, 0, 0] on the left arm.
render_layernonePalladium render layer drawn under the stones while at least one is inserted, e.g. a glove.
render_conditions[]Palladium conditions that must all pass for the render layer and stones to be drawn (checked on the client), e.g. only during an animation.
powers[]Extra power IDs given while it's worn, with or without stones.
tooltip_itemsitems named like the powerPower gauntlets only: item IDs or #tags whose tooltip lists the viewing player's stones. Item gauntlets always show the stones they hold.

A placement#

KeyDefaultMeaning
originrequired[x, y, z] corner of the stone's cube, in Blockbench (geo) coordinates of the player model.
slim_originorigin + slim_offsetCorner for slim arms when it differs (stones on the inner side of the arm don't move).
size[1, 0.9, 0.9]Cube size in pixels.
boneleft_armPlayer bone it follows: head, body, right_arm, left_arm, right_leg, left_leg.
rotation[0, 0, 0]Degrees around the cube's center.
Finding positions

Open the other mod's model in Blockbench, find the spot on the player's arm, and copy the origin of a 1 × 0.9 × 0.9 cube there. Moving a stone to another slot in the menu moves it on the model.

Checking for it#

Use infinity:custom_gauntlet in your own powers, optionally with gauntlet set to an ID:

JSON
{ "type": "infinity:custom_gauntlet", "gauntlet": "power_glove" }
