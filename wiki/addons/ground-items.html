Ground Items

Make an item lie still on the ground, survive anything, and only be picked up by right-clicking.

On this page
  1. What a ground item does
  2. Fields
  3. Opening animations
  4. Examples from the mod

What a ground item does#

A dropped or thrown item with a file in data/infinity/ground_items/ becomes an infinity:ground_item entity that:

  • It keeps the throw's motion, so it lands in front of you.
  • It's drawn as the dropped item (its model's ground display transform), lying still on the ground.
  • It keeps all of the stack's NBT (a gauntlet's stones and skin, names, enchantments and so on).
  • It can't be destroyed, burnt, blown up or despawn. If it falls out of the world it rests at the bottom, unless it is or holds an Infinity Stone (through release): then it reappears on the Overworld's surface near spawn and the server is told where.
  • Walking over it doesn't pick it up. Right-click it.

Old armor stand props from earlier versions are turned into ground items when their chunk loads.

Fields#

KeyDefaultMeaning
itemrequiredThe item. Must be registered. Each item can only be one ground item.
spinfalseSpin like a dropped item. Otherwise it lies still facing a random way.
bobfalseFloat and bob like a dropped item. Otherwise its lowest point rests on the ground.
scale1Size of the drawn item on the ground, on top of its ground display transform. Only the ground: held, worn and inventory rendering don't change. The Orb uses 0.5, since its item model is twice the size of the orb drawn in the hand.
width / height0.4Size of the box you right-click and hit, in blocks.
uniquefalseWhile a player carries this item, ground items of it disappear, so it can't be duplicated.
releasenoneHitting it breaks it open into items (each dropped as its own ground item, in the same spot) with a particle burst in color (#RRGGBB, default white). With an opening it plays that first and can't be picked up meanwhile. Ground items with a power always break open at once.
combine[][{"item": …, "result": …}]: right-clicking it on the ground while holding item uses one up and turns it into result where it lies. Give the other item the reverse entry so it works whichever is on the ground.
powernoneInstead of drawing the item, place it as an invisible small armor stand wearing the stack, drawn by this Palladium power's render layers (the gauntlet and Eye of Agamotto use this). release still works. spin, bob, scale, width, height and unique don't apply.
slotnoneWith power: the armor stand slot (head, chest, legs, feet, mainhand, offhand) that wears the stack, for render layers that read it. Left out, the stack stays hidden.

A file with the same name in a higher-priority pack replaces the mod's. Restart after changes.

Opening animations#

An opening inside release plays an animation between being hit and letting go of the items. The Tesseract and the Aether use one.

KeyDefaultMeaning
effectrequired"rays": Heroes Expansion's Tesseract, rising in a growing burst of rays in the release color, ending in a sphere of particles. "plume": the 1.12.2 Aether, red squares bursting out then pouring upward in a column, ending in an explosion.
duration100Ticks, at most 1200.
colorsthe release color["#RRGGBB", ...]: each plume square is a random shade between these.
modelthe item'sModel drawn instead of the item meanwhile, like the item without its lid.
parts[]Models that swing open: {"model": ..., "pivot": [x, y, z], "axis": "x"/"y"/"z", "angle": degrees, "ticks": 20}, pivot in model pixels.

Opening models are only loaded because a ground item names them. Give them "parent": "<the item's model>" and just their own elements, so they share its textures and ground transform.

Examples from the mod#

Container that breaks open

tesseract.json
{
  "item": "infinity:tesseract",
  "release": {
    "items": ["infinity:space_stone"],
    "color": "#66BFFF",
    "opening": { "effect": "rays", "duration": 100 }
  }
}

Opening with moving parts

aether.json
{
  "item": "infinity:aether",
  "release": {
    "items": ["infinity:reality_stone"],
    "color": "#FF261A",
    "opening": {
      "effect": "plume",
      "duration": 100,
      "colors": ["#C81828", "#F85060"],
      "model": "infinity:item/aether_open",
      "parts": [
        { "model": "infinity:item/aether_lid_left", "pivot": [5, 9, 8], "axis": "z", "angle": 75, "ticks": 20 },
        { "model": "infinity:item/aether_lid_right", "pivot": [11, 9, 8], "axis": "z", "angle": -75, "ticks": 20 }
      ]
    }
  }
}

Unique stone that combines

mind_stone.json
{
  "item": "infinity:mind_stone",
  "unique": true,
  "combine": [
    { "item": "infinity:empty_scepter", "result": "infinity:scepter" }
  ]
}

Drawn by a power

infinity_gauntlet.json
{
  "item": "infinity:infinity_gauntlet",
  "power": "infinity:gauntlet_ground",
  "slot": "head"
}

The mod ships ground item files for the six stones, the Tesseract, Scepter and Empty Scepter, Aether and Empty Aether, Orb, Eye of Agamotto, Infinity Gauntlet, Cosmi-Rod and both swords.
