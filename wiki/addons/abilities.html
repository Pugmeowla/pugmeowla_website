Ability & Condition Reference

The building blocks behind every stone, available to your own Palladium powers.

On this page
  1. Using them
  2. Ability types
  3. Conditions
  4. Other registered types

Using them#

All of these work in any Palladium power file (data/<namespace>/palladium/powers/*.json) like Palladium's own types. Properties left out use the defaults listed here. A power that gives a custom stone portals in a fire style might look like this:

data/example/palladium/powers/chaos_stone.json
{
  "name": "Chaos Stone",
  "icon": "example:chaos_stone",
  "gui_display_type": "tree",
  "abilities": {
    "sling_ring": {
      "type": "infinity:portal",
      "title": "Sling Ring",
      "style": "fire",
      "size": 1.5,
      "conditions": {
        "enabling": [ { "type": "palladium:action", "key_type": "key_bind", "cooldown": 40 } ]
      }
    },
    "blast": {
      "type": "infinity:energy_blast",
      "title": "Chaos Blast",
      "damage": 8.0,
      "color": "#E0115F",
      "scale_with_power_level": false,
      "conditions": {
        "enabling": [ { "type": "palladium:action", "key_type": "key_bind", "cooldown": 10 } ],
        "unlocking": [ { "type": "infinity:gauntlet_slot", "item": { "item": "example:chaos_stone" } } ]
      }
    }
  }
}

Palladium's generated documentation (mods/documentation/) lists the same types with the exact property formats for your installed version.

Ability types#

infinity:force_field#

While enabled, blocks hits from entities (melee, projectiles and other attacks with an attacker) dealing less than damage_threshold, and every hit from the always_blocked entity types. Damage without an attacker (falling, fire…) still goes through. Pair it with palladium:ability_enabled to tie it to a visible toggle, as the Space Stone does.

PropertyDefaultDescription
damage_threshold23.0Hits from entities dealing less than this much damage are blocked
always_blockediron_golem, warden, vindicator, piglin_brute, zombified_piglinEntity types whose hits are blocked no matter how strong
render_layernonePalladium render layer drawn on the entity while the force field is up
hit_soundnoneSound played when the force field blocks a hit

infinity:invulnerability#

Cancels all damage the entity takes while enabled, from every damage type (including other mods' types), unlike palladium:damage_immunity which only blocks the listed tags. Combine it with an enabling condition such as palladium:ability_enabled.

PropertyDefaultDescription
invulnerable_ticks20Hurt cooldown given each time a hit is blocked, so knockback and hurt effects don't stack; 0 leaves the normal cooldown
min_damage0.0Hits weaker than this still go through
negate_hitsfalseStops hits before they land at all: no knockback, red flash or hurt sound
particlenoneSimple particle shown around the entity when a hit is blocked

infinity:portal#

Players only. When enabled, opens the Space Stone portal menu (dimension with suggestions + coordinates). Opening it creates a linked pair of portals: one in front of the player, one at the destination. Use a palladium:action enabling condition.

PropertyDefaultDescription
textureinfinity:textures/gui/portal.pngMenu background: a square image in the 172×172 layout (dimension field at y 49, coordinates at y 75, button at y 104)
color#4DB3FFColor of the portals' ring and surface
styledefault"default", or "fire" for an orange portal in a spinning ring of flames like a sling ring portal (color is then unused)
size1.0Portal size; 1 is the normal 2.5 block tall portal

infinity:jump_portal#

Players only. When enabled, opens a pair of short-lived portals: one in front of the player and one at the block they look at, landing them on safe ground next to it. Use a palladium:action enabling condition.

PropertyDefaultDescription
range256.0How far away the looked-at block can be
color#4DB3FFAs infinity:portal
size1.0As infinity:portal
styledefaultAs infinity:portal

infinity:telekinesis#

Players only. Use with a palladium:toggle condition. Turning it on picks up the looked-at entity or solid block; scrolling moves it closer or further and attacking throws it. Turning it off sets it down. The toggle switches itself off when there's nothing to pick up or the target is thrown or lost. Unbreakable blocks and blocks with block entities can never be picked up.

PropertyDefaultDescription
range32.0How far away the target can be
launch_speed2.5Speed the target is thrown at
pick_up_entitiestrueWhether entities can be picked up
pick_up_blockstrueWhether blocks can be picked up
entity_whitelist[]Entity type IDs or #tags that can be picked up; empty allows all
entity_blacklist[]Entity type IDs or #tags that can never be picked up
block_whitelist[]Block IDs or #tags that can be picked up; empty allows all
block_blacklist[]Block IDs or #tags that can never be picked up

infinity:spatial_lock#

Players only. While unlocked, right-clicking while holding something with infinity:telekinesis locks it in place. Use it as a skill tree unlock with "hidden_in_bar": true and no enabling conditions.

infinity:black_hole#

Players only. Use with a palladium:toggle condition. Turning it on summons a growing black hole in front of the player that follows their aim and pulls in entities and blocks; attacking throws it, and it collapses on its own later. Turning it off before throwing collapses it.

infinity:clones#

Players only. Replaces the player's clones with new copies around them. Clones copy the player's look, follow and defend them, attack what they hit, and vanish after their lifetime or when the player dies. Use a palladium:action condition with a cooldown.

PropertyDefaultDescription
count3Number of clones
lifetime1200Ticks each clone lasts
spread2.0Distance from the player they appear at
health20.0Max health of each clone
confuse_enemiestrueMobs targeting the player pick randomly between the player and nearby clones

infinity:mind_reading#

Players only. Opens a read-only snapshot of the looked-at living entity: info card, effects, equipment and inventory. Use a palladium:action condition.

PropertyDefaultDescription
range32.0How far away the entity can be
show_inventorytrueWhether the inventory is shown below the equipment

infinity:disguise#

Players only. Opens a menu to type a username and wear that player's skin and name, or Reset. Worn while any infinity:disguise ability is unlocked. Use a palladium:action condition.

infinity:energy_blast#

Fires a glowing energy blast where the entity looks that damages the first entity it hits. Use a palladium:action condition.

PropertyDefaultDescription
damage3.0Damage dealt
color#FF00FFColor of the blast
speed1.5Blocks per tick
scale_with_power_leveltrueMultiplies the damage by 2^level of infinity:power_level (infinite when maxed)

infinity:power_blast#

A palladium:energy_beam whose damage is 2^level of the entity's infinity:power_level. When maxed it switches to max_energy_beam, runs max_commands_on_block_hit and explodes where it hits blocks. damage, energy_beam and commands_on_block_hit are set by the ability itself; the other energy_beam properties work as usual.

PropertyDefaultDescription
max_energy_beaminfinity:gauntlet_beam_rainbowBeam used at max level with all six stones
max_commands_on_block_hit[]Commands run when the max-level beam hits a block
max_explosion_power4.0Explosion power where the max beam hits a block, every tick (0 for none)

infinity:power_level#

Players only. Gives the power a level from 0 to max_level, stored in a scoreboard objective (for energy bars and objective_score conditions). Infinity's damage abilities scale with the first enabled power_level the player has. Usually hidden and always enabled.

PropertyDefaultDescription
objectiveDamageCycleScoreboard objective the level is stored in
max_level11Highest level
unlock_abilities[]Abilities that unlock each level, in order; level n is reachable once the first n are unlocked. Empty: every level is available
scale_attack_damagetrueWhether base attack damage is set to 2^level
max_requires_powers[]Powers the player must also have for max_level to count as maxed (infinite damage)

infinity:power_level_change#

Players only. Each time it's enabled, changes the infinity:power_level by amount, staying between 0 and the highest unlocked level. Pair a +1 and a −1 copy with scroll_up / scroll_down action conditions.

PropertyDefaultDescription
amount1Levels added each time (negative lowers)

infinity:rocket_burst#

Launches a burst of homing rockets from the hand the power comes from (the off hand with a gauntlet). Rockets explode on impact and never hurt their shooter.

PropertyDefaultDescription
rockets5Rockets launched at once
scale_with_power_leveltrueScales damage by level ÷ max_level; full damage when false
soundinfinity:power_stone_explodeSound the user hears on launch

infinity:power_cyclone#

Star Tech's Power Stone cyclone: a ring of explosion particles and a Power Stone rocket every second.

infinity:power_radiation#

Client render effect: glowing cracks spreading over the skin as the named animation timer counts up. Hidden by default.

PropertyDefaultDescription
timer_abilitytimerAnimation timer ability in the same power; its value is the radiation's age in ticks
stoneinfinity:power_stoneGauntlet stone whose color the cracks take

infinity:meteor_storm#

Players only. Pulls a moon of the given size onto the spot the player looks at, breaking into meteors on the way down. One storm per player at a time.

PropertyDefaultDescription
size1Size of the moon in blocks
scale_with_power_leveltrueAdds the infinity:power_level to the size

infinity:shockwave#

Star Tech's Concussive Blast: rings of energy from the hand for the given ticks; everything in front (in a box growing up to 4 blocks) is flung along the look and hurt every tick. Use an action condition with a cooldown.

PropertyDefaultDescription
damage5.0Damage every tick of the blast
duration7Ticks the blast lasts
speed3.0Speed added along the look every tick

infinity:movement_lock#

Stops the player walking, strafing and jumping, and optionally changing hotbar slot.

PropertyDefaultDescription
lock_hotbartrueWhether the hotbar slot is locked too (never in creative)

infinity:potion_effect#

Keeps a potion effect applied while enabled, refreshing it only shortly before it runs out.

PropertyDefaultDescription
effectminecraft:slownessEffect to keep applied
amplifier00 = level I
duration20Ticks applied each time
refresh_at10Remaining ticks at which it's topped up
hide_particlestrueHide particles and icon

infinity:reality_copy#

Players only. Saves the looked-at block (not unbreakable ones) for infinity:reality_paste. Kept through death and relogging; shown by the infinity:reality_saved_block icon. Use an action condition.

PropertyDefaultDescription
range30.0How far away the block can be

infinity:reality_paste#

Players only. Turns the looked-at block into the saved Reality block, or every non-air block within sneak_radius while sneaking. Respects build permissions and protection.

PropertyDefaultDescription
range30.0How far away the block can be
sneak_radius5Sphere radius while sneaking (1 = only the looked-at block)

infinity:time_flow#

Players only. Requires Chrono API. Use with a toggle. While on, the whole server runs at the tick rate of the player's current step; off returns to 20 TPS. Give the user infinity:time_immunity.

PropertyDefaultDescription
objectivetickrateCycleObjective the current step is stored in
display_objectivetimestonesidebarObjective set to step + 6 (1–11), for an energy bar
min_step-5Fastest step; each step below 0 adds 4 TPS (−5 = 40 TPS)
max_step5Slowest step; each step above 0 removes 4 TPS, 5 or more is 2 TPS
compensatetrueHidden Speed and Haste for the user while time is slowed

infinity:time_flow_change#

Players only. Each time it's enabled while infinity:time_flow is on, moves the step by amount. Pair +1 and −1 copies with scroll conditions.

PropertyDefaultDescription
amount1Steps added: positive slows time, negative speeds it up

infinity:time_freeze#

Requires Chrono API. Use with a toggle. While on, time is frozen for the whole server; give the user infinity:time_immunity.

infinity:time_immunity#

Requires Chrono API. While enabled the entity keeps moving at normal speed when the tick rate changes or time is frozen, and players are whitelisted from those changes. Hidden by default.

infinity:time_set#

Players only. While enabled, /infinity time set <time> works for the player.

infinity:projectile_stop#

While enabled, freezes projectiles (#infinity:projectiles) that come within range. They hang in the air for duration ticks, then continue. Survives reloads.

PropertyDefaultDescription
range2.5Projectiles closer than this are stopped
duration1000Ticks they hang in the air

infinity:soul_storage#

Players only. While enabled, every kill stores one soul, up to max (not clones or drained mobs), in a scoreboard objective.

PropertyDefaultDescription
objectiveSoulStorageObjective the souls are stored in
max50Most souls that can be stored

infinity:soul_heal#

Players only. Spends cost souls to restore heal health. Does nothing at full health or without enough souls.

PropertyDefaultDescription
heal4.0Health restored (2 = one heart)
cost1Souls spent

infinity:soul_drain#

Players only, needs an enabled infinity:soul_storage. Drains the looked-at mob (AI off, greyscale) for souls; while sneaking gives a drained mob its soul back. Players, #forge:bosses, clones and AI-less mobs can't be drained.

PropertyDefaultDescription
range8.0How far away the mob can be
souls1Souls gained per drain and spent per restore

infinity:pocket_dimension_enter#

Players only. Takes the player and every entity in range to the dimension, remembering where each came from.

PropertyDefaultDescription
dimensioninfinity:soulworldDimension to go to
range5.0Radius of entities taken along
arrival_y72.0Arrival height (same X/Z)
tagin_soulScoreboard tag added to the player (empty for none)

infinity:pocket_dimension_exit#

Players only. In the dimension, sends the player and every entity in range back to where each came from (or to arrival_y in the overworld with slow falling).

PropertyDefaultDescription
dimensioninfinity:soulworldDimension to leave
range5.0Radius of entities sent back
arrival_y72.0Overworld height for entities with no origin
tagin_soulScoreboard tag removed from the player

infinity:locate_player#

Players only. While enabled, /infinity soul locateplayer <player> works for the player.

infinity:eye_of_agamotto#

Players only. Acts on the worn Eye of Agamotto (chest or Curios necklace). Use with an action condition and the infinity:eye_of_agamotto condition.

PropertyDefaultDescription
actionopenopen, close, remove_stone or insert_stone

infinity:gauntlet_skin_layer#

Renders the skin of the gauntlet at the given position, as defined in data/infinity/gauntlet_skins.

PropertyDefaultDescription
positionwornworn (off hand / Curios), mainhand or ground (armor stand head)

infinity:gauntlet_stones_layer#

Renders the stones of the gauntlet at the given position, each in the slot it occupies.

PropertyDefaultDescription
positionwornworn, mainhand, ground, custom (the worn custom gauntlet) or head (stones with "head": true in the Curios head slot)

Conditions#

infinity:gauntlet_slot#

The given stone is installed, in any slot, in the worn gauntlet: an Infinity Gauntlet in the off hand or Curios hands slot, otherwise a custom gauntlet.

PropertyDefaultDescription
item—Stone as an ingredient, e.g. {"item": "infinity:power_stone"}

infinity:gauntlet_slot_mainhand#

The given stone is installed, in any slot, in the Infinity Gauntlet in the main hand.

PropertyDefaultDescription
item—Stone as an ingredient

infinity:stone_equipped#

The Infinity Stone is in the active gauntlet, a held Cosmi-Rod, or the Curios head slot.

PropertyDefaultDescription
stoneinfinity:power_stoneStone item ID

infinity:gauntlet_skin#

The relevant Infinity Gauntlet has the given skin. Empty checks for no skin; "*" for any skin. Skins that no longer exist count as no skin.

PropertyDefaultDescription
skin""Skin ID
main_handfalseCheck the gauntlet in the main hand instead
groundfalseCheck the gauntlet on a ground armor stand's head

infinity:gauntlet_visible#

The worn gauntlet should be drawn: false when it's only in a Curios hands slot whose visibility button is off. Use it on render layers.

infinity:custom_gauntlet#

The active gauntlet is a custom gauntlet (an Infinity Gauntlet in the off hand or Curios hands takes priority), optionally a specific one.

PropertyDefaultDescription
gauntlet""Custom gauntlet ID (file name); empty for any

infinity:double_action#

Like palladium:action, but the key must be pressed twice within confirm_ticks; the first press only shows the message.

PropertyDefaultDescription
confirm_ticks60Ticks the second press must come within
messagePress again to confirmAction bar message after the first press

infinity:double_toggle#

Like palladium:toggle, but turning it on needs two presses within confirm_ticks. Turning it off is one press.

PropertyDefaultDescription
confirm_ticks60Ticks the second press must come within
messagePress again to confirmAction bar message after the first press

infinity:eye_of_agamotto#

Checks the Eye of Agamotto worn on the chest or Curios necklace slot.

PropertyDefaultDescription
openanytrue/false: whether it is open
stoneanyWhether the Time Stone is in it
open_foranyTicks it has been open (e.g. to show the glow after the animation)

infinity:telekinetic_grip#

The player is holding something with infinity:telekinesis, optionally matching entities and/or blocks. Server side: use in ability conditions, not render layers.

PropertyDefaultDescription
entities[]Entity type IDs or #tags the held entity must match
blocks[]Block IDs or #tags the held block must match

infinity:telekinetic_hold#

The entity is being held by someone's infinity:telekinesis. Server side.
