Commands

7.3's commands come from KubeJS scripts and aren't under /infinity.

On this page
  1. /space_tp
  2. /time_set
  3. /locateplayer
  4. /unlockstones
  5. /unlock_orb

/space_tp#

COMMAND
/space_tp <x> <y> <z> <dimension>

Needs the Space Stone's Teleport Command. Takes you and everything within 3 blocks to those coordinates in that dimension, with a portal effect. The ability's description only mentions x, y and z, but the dimension is needed too.

Example
/space_tp 212 130 99 infinity:vormir

/time_set#

COMMAND
/time_set <time>

Needs the Time Stone's Time Command. Runs /time set with whatever you give it, like day, night or 6000.

/locateplayer#

COMMAND
/locateplayer <target>

Needs the Soul Stone's Locate Entity Command. Tells you where a player is. Without the ability you get "You are not worthy to use the Soul Stone's locate ability."

/unlockstones#

COMMAND
/unlockstones

Operators only (level 2). Unlocks every ability of all six stones for you.

/unlock_orb#

COMMAND
/unlock_orb

Operators only (level 2). Unlocks the Orb's combination for you.
