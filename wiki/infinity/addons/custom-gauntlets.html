Custom Gauntlets

Turn an Omnitrix, an Iron Man suit or any glove into an Infinity Gauntlet with one JSON file, without the other mod knowing.

How it works#

Each custom gauntlet is a file in data/<namespace>/infinity/gauntlets/, where <namespace> is your mod or pack ID. Its ID is <namespace>:<file name>, so it can't replace another mod's gauntlet. The older data/infinity/gauntlets/ folder still works, with just the file name as the ID (Infintrix and Infinity Protocol use it). You describe what counts as wearing it, where each stone is drawn, and optional extras. While a player wears it, everything works like the real gauntlet:

Stone menu
The Open Gauntlet key (G) opens it for the gauntlet in your main hand, otherwise the worn one, so gauntlets that are never held still work. It looks like the Infinity Gauntlet's menu unless the file has a gui.
Stones
All six, and custom stones, fit. No duplicates. Item gauntlets store them on the item (they stay with it). Power gauntlets store them on the player per gauntlet ID (they come back when it's put on again).
Abilities
With at least one stone inserted, the player gets infinity:infinity_gauntlet, so stones are used and snapped exactly as with the real gauntlet.
Look
The other mod draws its object as usual. With a stone inserted, the optional render_layer (e.g. a glove) is drawn on top, and each stone as a small stone cube on a bone of the player model, following that arm's animation.

An Infinity Gauntlet in the off hand or Curios hands slot takes priority, then custom gauntlets in file name order.

Worked examples#

The first five are the real files from Infintrix, Infinity Protocol and Herbs of Wakanda. Their six positions are the Infinity Gauntlet's own sockets, a good start for anything on the left hand.

Omnitrix with a glove

Infintrix's Prototype Omnitrix from Alien Evolution. While the player has the Omnitrix's power it's a gauntlet, and once a stone is in, the infintrix:prototype_infintrix glove is drawn under the stones. Each stone has its own slim_origin, since slim arms are narrower.

data/infinity/gauntlets/prototype_omnitrix.json
{
  "name": "Prototype Omnitrix",
  "equipment": {
    "power": "alienevo:prototype_omnitrix"
  },
  "slots": [
    { "origin": [7.5856, 11.6159, -1.1051], "slim_origin": [6.4852, 11.6159, -1.1051], "size": [0.961, 0.8649, 0.8649] },
    { "origin": [7.5856, 12.8571, -0.5285], "slim_origin": [6.4852, 12.8571, -0.5285], "size": [0.961, 0.8649, 0.8649] },
    { "origin": [7.5856, 11.6159, 0.1441], "slim_origin": [6.4852, 11.6159, 0.1441], "size": [0.961, 0.8649, 0.8649] },
    { "origin": [7.5856, 11.6159, -2.2583], "slim_origin": [6.4852, 11.6159, -2.2583], "size": [0.961, 0.8649, 0.8649] },
    { "origin": [4.6066, 12.0003, -2.5465], "slim_origin": [4.701, 12.0003, -2.4465], "size": [0.8649, 0.8649, 0.8649] },
    { "origin": [7.5856, 11.6159, 1.3934], "slim_origin": [6.4852, 11.6159, 1.3934], "size": [0.961, 0.8649, 0.8649] }
  ],
  "render_layer": "infintrix:prototype_infintrix",
  "powers": ["infintrix:infintrix"]
}

The glove's render layer

A normal GeckoLib Palladium render layer, with a slim arm version. Its texture gets an overlay picked by the watch's AlienEvo.BasePrimary score, so the glove matches the colour the player gave the Omnitrix.

assets/infintrix/palladium/render_layers/prototype_infintrix.json
{
  "type": "geckolib:default",
  "model": {
    "normal": "infintrix:geo/prototype_infintrix.geo.json",
    "slim": "infintrix:geo/prototype_infintrix_slim.geo.json"
  },
  "texture": {
    "base": "infintrix:textures/models/prototype_infintrix.png",
    "transformers": [
      { "type": "palladium:overlay", "overlay": "infintrix:textures/models/prototype_glove/primary_#A.png" }
    ],
    "variables": {
      "A": { "type": "palladium:objective_score", "objective": "AlienEvo.BasePrimary" }
    },
    "output": "infintrix:textures/models/prototype_glove/glove_#A.png"
  },
  "bones": {
    "head": "head",
    "body": "body",
    "right_arm": "right_arm",
    "left_arm": "left_arm",
    "right_leg": "right_leg",
    "left_leg": "left_leg"
  }
}

Stones on a watch face

Infintrix's Omniverse Omnitrix has no glove. Its stones are thin slivers around the watch face, two rows of three.

    { "origin": [7.75, 13.6, 0.288], "size": [0.9, 0.25, 0.29] },
    { "origin": [7.75, 16.15, 0.288], "size": [0.9, 0.25, 0.29] },

Iron Man suit

Infinity Protocol's Mark 85 from Satsu's Iron Man Addon. It's an item gauntlet worn in that mod's suit slot, and its render_conditions wait until the suit's left arm has fully formed before the nano gauntlet and stones are drawn.

data/infinity/gauntlets/protocol_mark_85.json
{
  "name": "Mark 85",
  "equipment": {
    "item": "satsu_iron_man_addon:marks/mark_85/main",
    "slots": ["curios:tecnology_armor"]
  },
  "slots": [
    { "origin": [7.65, 11.75, -1.15] },
    { "origin": [7.65, 13.25, -0.55] },
    { "origin": [7.65, 11.75, 0.15] },
    { "origin": [7.65, 11.75, -2.35] },
    { "origin": [4.55, 12.15, -2.65], "size": [0.9, 0.9, 0.9] },
    { "origin": [7.65, 11.75, 1.45] }
  ],
  "render_layer": "infinity:nano_gauntlet_85",
  "render_conditions": [
    {
      "type": "palladium:string_property",
      "property": "satsu_iron_man_addon.left_arm",
      "comparator": "equals",
      "compare_to": "on"
    },
    {
      "type": "palladium:ability_integer_property",
      "power": "satsu_iron_man_addon:iron_man/marks/mark_85/main",
      "ability": "left_arm_animation",
      "property": "value",
      "min": 17,
      "max": 17
    }
  ],
  "powers": ["infinity_protocol:suit"]
}

A necklace

Herbs of Wakanda's Black Panther's Necklace, worn on the chest or in the Curios necklace slot. Its stones are placed on the body bone, in a row across the chest.

data/infinity/gauntlets/black_panther_necklace.json
{
  "name": "Black Panther's Necklace",
  "equipment": {"item": "wakanda:black_panther_necklace", "slots": ["curios:necklace", "chest"]},
  "slots": [
    {"bone": "body", "origin": [-1.1, 20.3, -2.9], "size": [1, 1, 0.8]},
    {"bone": "body", "origin": [1.25, 21.4, -2.9], "size": [1, 1, 0.8]},
    {"bone": "body", "origin": [2.45, 22.55, -2.9], "size": [1, 1, 0.8]},
    {"bone": "body", "origin": [-2.25, 21.4, -2.9], "size": [1, 1, 0.8]},
    {"bone": "body", "origin": [0.1, 20.3, -2.9], "size": [1, 1, 0.8]},
    {"bone": "body", "origin": [-3.45, 22.55, -2.9], "size": [1, 1, 0.8]}
  ]

An item

An item gauntlet keeps its stones on the item. Here a Power Glove item from the infinity_test_stone pack counts while it's in the Curios hands slot or the off hand.

data/infinity/gauntlets/power_glove.json
{
  "name": "Power Glove",
  "equipment": { "item": "infinity_test_stone:power_glove", "slots": ["curios:hands", "offhand"] },
  "slots": [
    { "origin": [7.65, 11.75, -1.15] },
    { "origin": [7.65, 13.25, -0.55] },
    { "origin": [7.65, 11.75, 0.15] },
    { "origin": [7.65, 11.75, -2.35] },
    { "origin": [4.55, 12.15, -2.65], "size": [0.9, 0.9, 0.9] },
    { "origin": [7.65, 11.75, 1.45] }
  ],
  "slim_offset": [-1, 0, 0]
}

Equipment#

{"item": "<id>", "slots": [...]}

Worn when
That item is in one of the slots: mainhand, offhand, head, chest, legs, feet, curios:<slot>, trinkets:<group/slot>. Without slots: main hand and off hand.
Stones are kept
On that item

{"power": "<id>"}

Worn when
The player has that power, e.g. a coupled Omnitrix (the item becomes a power while worn).
Stones are kept
On the player, per gauntlet

Fields#

name

Default
Infinity Gauntlet
Meaning
Title of the stone menu (text component).

equipment

Default
required
Meaning
See above.

slots

Default
[]
Meaning
Placements, by menu slot (the Infinity Gauntlet menu's six slots are Space, Mind, Reality, Power, Time, Soul). null leaves a slot undrawn. A stone in it still works.

gui

Default
the Infinity Gauntlet's menu
Meaning
The stone menu's texture and slots. See below.

slim_offset

Default
[0, 0, 0]
Meaning
Added to every origin for slim-armed players, usually [-1, 0, 0] on the left arm. Leave it out when the stones sit on armor or a glove that's always drawn at classic width, or they end up inside it.

render_layer

Default
none
Meaning
Palladium render layer drawn under the stones while at least one is inserted, e.g. a glove.

render_conditions

Default
[]
Meaning
Palladium conditions that must all pass for the render layer and stones to be drawn (checked on the client), e.g. only during an animation.

first_person_tilt

Default
false
Meaning
Draws the arm wearing it tilted in first person, like the Infinity Gauntlet's, while it's worn and render_conditions pass. For an item in your hand, that's the hand holding it. Worn anywhere else (or as a power), it's the arm its stones are on, while that hand is empty.

scale

Default
1
Meaning
Size of every stone cube on it, each about its own center, on top of the placements' size and the stones' own scale. A number, or {"base": 1, "width": 1, "height": 1} to stretch them. The render_layer isn't scaled.

powers

Default
[]
Meaning
Extra power IDs given while it's worn, with or without stones.

tooltip_items

Default
items named like the power
Meaning
Power gauntlets only: item IDs or #tags whose tooltip lists the viewing player's stones. Item gauntlets always show the stones they hold.

A placement#

origin

Default
required
Meaning
[x, y, z] corner of the stone's cube, in Blockbench (geo) coordinates of the player model.

slim_origin

Default
origin + slim_offset
Meaning
Corner for slim arms when it differs (stones on the inner side of the arm don't move).

size

Default
[1, 0.9, 0.9]
Meaning
Cube size in pixels.

bone

Default
left_arm
Meaning
Player bone it follows: head, body, right_arm, left_arm, right_leg, left_leg.

rotation

Default
[0, 0, 0]
Meaning
Degrees around the cube's center.
Finding positions

Open the other mod's model in Blockbench, find the spot on the player's arm, and copy the origin of a 1 × 0.9 × 0.9 cube there. Moving a stone to another slot in the menu moves it on the model.

The stone menu (gui)#

Without gui, a custom gauntlet uses the Infinity Gauntlet's own menu, with its texture and six stone slots. With it, the menu can look like anything and have 1 to 27 slots, each taking stones or other items.

&quot;gui&quot; in a custom gauntlet file
"gui": {
  "texture": "infinity_test_stone:textures/gui/power_glove.png",
  "size": [176, 166],
  "inventory": [8, 84],
  "title": [8, 6],
  "slots": [
    {"pos": [44, 20]},
    {"pos": [62, 20]},
    {"pos": [80, 20]},
    {"pos": [98, 20]},
    {"pos": [116, 20]},
    {"pos": [134, 20]},
    {"pos": [80, 50], "accepts": ["minecraft:nether_star", "#forge:gems/diamond"], "max_stack": 16}
  ]
}

texture

Default
infinity:textures/gui/infinity_gauntlet.png
Meaning
Background image.

size

Default
[256, 256]
Meaning
[width, height] of the menu: the part of the texture that's drawn (up to 1024).

texture_size

Default
size, at least [256, 256]
Meaning
[width, height] of the texture file.

inventory

Default
[48, 153]
Meaning
[x, y] of the player inventory's top left slot. The hotbar is 58 pixels below.

title

Default
none
Meaning
[x, y] to write the gauntlet's name at. Left out, there's no title.

slots

Default
the six stone slots
Meaning
1 to 27 slots, in order.

A slot#

pos

Default
required
Meaning
[x, y] of the slot's top left corner, where the 16×16 item is drawn. Line it up with the slot in your texture.

accepts

Default
"stones"
Meaning
"stones" (any Infinity Stone, custom stones included), "any", or a list of item IDs and #tags.

max_stack

Default
1
Meaning
1 to 64. Stone slots always hold one.
  • Change the texture: set texture (and size / texture_size if it isn't 256×256), then move inventory and the slots to where your image draws them.
  • Add or remove slots: add or remove entries in slots. A slot's index is also its index in the top level slots placements, so the stone in slot 3 is drawn at placement 3.
  • Move a slot: change its pos.

A stone counts as inserted in any slot, and one stone can only be in one slot at a time. The server sends the menu to the client, so both always agree even if the client has a different copy of the file. Bad values are logged (Custom gauntlet <id>: ...) and fall back to the Infinity Gauntlet's, so a broken file never crashes the game. If a menu gets fewer slots than it had, whatever was in the removed slots is handed back the next time it's opened. Items in slots that no longer accept them stay put and can still be taken out. Nothing stored is ever deleted.

Checking for it#

Use infinity:custom_gauntlet in your own powers, optionally with gauntlet set to an ID:

JSON
{ "type": "infinity:custom_gauntlet", "gauntlet": "prototype_omnitrix" }

For a gauntlet in a namespaced folder, use its full ID, like "gem_core:power_glove".
