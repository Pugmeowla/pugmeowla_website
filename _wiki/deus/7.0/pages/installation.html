--- title: Installation description: What Deus Chrono-Machina needs to run and how to install it. lead: Deus Chrono-Machina is a Forge mod for Minecraft 1.20.1. It adds to Alien Evolution, so that has to be installed too. icon: deus/logo.png ---

Requirements

Minecraft Forge

Version
1.20.1, Forge 47 or newer
Mod ID
forge

Alien Evolution

Version
2.0.0 or newer (the Java edition)
Mod ID
alienevo

Palladium

Version
4.5.0 or newer
Mod ID
palladium

Chrono API

Version
1.0.3 up to 2.0
Mod ID
chrono_api

Alien Evolution brings its own requirements (Palladium and TerraBlender among them). All of them have to be on both the client and the server.

Installing

  1. Install Forge for 1.20.1 and start the game once.
  2. Put Deus Chrono-Machina, Alien Evolution, Palladium and Chrono API in your mods folder.
  3. Start the game. Deus Chrono-Machina has its own creative tab with every item.
