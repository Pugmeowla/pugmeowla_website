How it works

Every item that can go in the Infinity Gauntlet has a file in data/infinity/gauntlet_stones/, including the six Infinity Stones. Once an item has one:

  • It fits in any of the gauntlet's six slots (but not twice), in custom gauntlets and in the Cosmi-Rod.
  • Everything is drawn from what's actually in each slot. The gauntlet's inventory icon colors that slot's pixel (textures/item/gauntlet_slots/slot_[n].png), and the worn, held and ground models draw the stone on that slot's socket (geo/gauntlet_slots/slot_[n].geo.json).
  • It looks like a 1.12.2 stone everywhere: its texture tinted with color, unlit, with two scrolling glints in glint_color.
  • Its power is given while it's in any slot of the active gauntlet and taken away as soon as it comes out.
  • The gauntlet's tooltip lists it as " - Name" in tooltip_color, sorted by tooltip_order.

Fields

KeyDefaultMeaning
itemrequiredThe stone's item. It has to be registered, and an item can only be one stone.
color#FFFFFF#RRGGBB. Tints the stone everywhere (item, gauntlet worn, held, on the ground, inventory icon, head) and colors its tooltip line and insert particles.
glinttrueWhether the two scrolling glints are drawn.
glint_colorcolor#RRGGBB color of the glints.
tooltip_colorcolorColor of its line in the gauntlet tooltip. A chat color name (aqua, light_purple…) or #RRGGBB.
tooltip_order100Where it goes in the tooltip. Lower comes first. The six stones use 0 to 5.
powernonePalladium power given while the stone is in any slot of the active gauntlet (off hand or Curios hands). In a Cosmi-Rod, a stone without power gives the power with the same ID as the item.
headfalseLets the stone go in the Curios head slot, where it's drawn on the forehead and gives its power.
textureinfinity:textures/item/infinity_stone.pngThe stone cube's texture, tinted by color. Uses the 1.12.2 layout, a 6×6×6 box UV cube on a 32×16 texture.

Example

Stone file

{
  "item": "example:chaos_stone",
  "color": "#E0115F",
  "glint_color": "#FF7AA8",
  "tooltip_color": "#E0115F",
  "tooltip_order": 10,
  "power": "example:chaos_stone",
  "head": true
}

Item model

To give the item the stone look in your inventory, use the mod's stone model as its parent:

{
  "parent": "infinity:item/infinity_stone"
}

The real Time Stone

{
  "item": "infinity:time_stone",
  "color": "#13CF55",
  "glint_color": "#12E772",
  "tooltip_color": "green",
  "tooltip_order": 4
}

The six built-in stones don't have a power, because the gauntlet power hands those out itself.

Drawing a stone yourself

Palladium render layers can draw any stone with the stone look using the layer type infinity:stone:

{
  "type": "infinity:stone",
  "stone": "example:chaos_stone",
  "model": "example:geo/chaos_stone_socket.geo.json"
}

Checking for a stone

Use the infinity:gauntlet_slot condition (or infinity:gauntlet_slot_mainhand for a held gauntlet) in other powers. See {{page addons/abilities.html#conditions Conditions}}.

{
  "type": "infinity:gauntlet_slot",
  "item": { "item": "example:chaos_stone" }
}

Making it act like a stone on the ground

Add a {{page addons/ground-items.html ground item}} file with "unique": true so dropped copies can't be duplicated.
