--- title: Custom Stones description: The gauntlet_stones format. Make any item fit in the Infinity Gauntlet and Cosmi-Rod, with its own color, glint, tooltip, head slot support and power. lead: Any item can be an Infinity Stone. One file makes it fit the gauntlet, look like a stone and give a power. icon: stones/time_stone.png ---

How it works

Every item that can go in the Infinity Gauntlet has a file in data/<namespace>/infinity/gauntlet_stones/ (your mod or pack ID as the namespace), or in the older data/infinity/gauntlet_stones/ where the six Infinity Stones' files are. Once an item has one:

  • It fits in any of the gauntlet's six slots (but not twice), in custom gauntlets and in the Cosmi-Rod.
  • Everything is drawn from what's actually in each slot. The gauntlet's inventory icon colors that slot's pixel (textures/item/gauntlet_slots/slot_[n].png), and the worn, held and ground models draw the stone on that slot's socket (geo/gauntlet_slots/slot_[n].geo.json).
  • It looks like a 1.12.2 stone everywhere: its texture tinted with color, unlit, with two scrolling glints in glint_color.
  • Its power is given while it's in any slot of the active gauntlet and taken away as soon as it comes out.
  • The gauntlet's tooltip lists it as " - Name" in tooltip_color, sorted by tooltip_order.

Fields

KeyDefaultMeaning
itemrequiredThe stone's item. It has to be registered, and an item can only be one stone.
color#FFFFFF#RRGGBB. Tints the stone everywhere (item, gauntlet worn, held, on the ground, inventory icon, head) and colors its tooltip line and insert particles.
glinttrueWhether the two scrolling glints are drawn.
glint_colorcolor#RRGGBB color of the glints.
tooltip_colorcolorColor of its line in the gauntlet tooltip. A chat color name (aqua, light_purple…) or #RRGGBB.
tooltip_order100Where it goes in the tooltip. Lower comes first. The six stones use 0 to 5.
powernonePalladium power given while the stone is in any slot of the active gauntlet (off hand or Curios hands), and while it's held if hand is on. In a Cosmi-Rod, a stone without power gives the power with the same ID as the item.
handtrueGives the stone's power while the stone itself is held in either hand. The six built-in stones set it to false, because their held power comes from their own item powers.
headfalseLets the stone go in the Curios head slot, where it's drawn on the forehead and gives its power.
textureinfinity:textures/item/infinity_stone.pngThe stone cube's texture, tinted by color. Uses the 1.12.2 layout, a 6×6×6 box UV cube on a 32×16 texture.
scale1Size of the stone wherever it's drawn (in the gauntlet, on the head, held and on the ground, but not in inventories), about its own center. A number, or {"base": 1, "width": 1, "height": 1} to stretch it (width is x and z, each times base). 0 counts as 1.
glow_abilities[]Abilities that make the stone glow brighter while one is on for whoever holds or wears it (gauntlet, custom gauntlet, Cosmi-Rod, head or hand). An ability of the stone's own power by name, or any ability as power#ability. Best for abilities that stay on for a while: held keys and toggles.
glow_colorcolor#RRGGBB added over the stone while it glows, pulsing slowly.

Example

Stone file

The Test Stone from the {{page addons/index.html#addon-pack test pack}}:

{
  "item": "infinity_test_stone:test_stone",
  "color": "#FF69B4",
  "glint_color": "#FFC2E2",
  "tooltip_order": 6,
  "power": "infinity_test_stone:test_stone"
}

Item model

To give the item the stone look in your inventory, use the mod's stone model as its parent:

{
  "parent": "infinity:item/infinity_stone"
}

The real Time Stone

{
  "item": "infinity:time_stone",
  "color": "#13CF55",
  "glint_color": "#12E772",
  "tooltip_color": "green",
  "tooltip_order": 4,
  "power": "infinity:time_stone",
  "hand": false,
  "glow_abilities": [
    "reset_time_speed",
    "time_freeze",
    "fast_forward",
    "projectile_stop"
  ]
}

The six built-in stones name their own power like any addon stone, so the gauntlet gives it out the same way.

Containers that glow with their stone

An item that holds a stone, like the Scepter or the Tesseract, can glow along with it. Each one is a file in data/<namespace>/infinity/stone_containers/. Only the item's own model changes: held, on the ground and in inventories. Problems are logged as Stone container <id>: …. Restart after changes.

KeyDefaultMeaning
itemrequiredThe container's item.
stonenoneThe stone inside it. Its glow_color, glow_abilities and power are the defaults for the keys below.
glow_abilitiesthe stone'sAbilities that make it glow while one is on for whoever holds it: by name for one of power's abilities, or power#ability.
powerthe stone'sThe power whose abilities glow_abilities names without a power#.
glow_colorthe stone's, or #FFFFFF#RRGGBB added over it while it glows.
glow_texturenoneA mask laid over the item's texture: only its non-transparent pixels glow, whatever their color. It should match the item texture's layout. Without it the whole item glows.
 
{
  "item": "infinity:scepter",
  "stone": "infinity:mind_stone",
  "glow_texture": "infinity:textures/item/scepter_e.png"
}

The mod ships files for the Tesseract, Aether, Eye of Agamotto and Scepter. The Tesseract's has no mask, so the whole cube glows.

Drawing a stone yourself

Palladium render layers can draw any stone with the stone look using the layer type infinity:stone:

{
  "type": "infinity:stone",
  "stone": "infinity_test_stone:test_stone",
  "model": "infinity_test_stone:geo/test_stone_socket.geo.json"
}

Checking for a stone

Use the infinity:gauntlet_slot condition (or infinity:gauntlet_slot_mainhand for a held gauntlet) in other powers. See {{page addons/abilities.html#conditions Conditions}}.

{
  "type": "infinity:gauntlet_slot",
  "item": { "item": "infinity_test_stone:test_stone" }
}

Making it act like a stone on the ground

Add a {{page addons/ground-items.html ground item}} file with "unique": true so dropped copies can't be duplicated.
