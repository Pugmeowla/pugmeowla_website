All of these act on the player who runs them, so they have to be run by a player and not the console or a command block. The one exception is soulguardian respawn. Otherwise you'll get "This command can only be used by a player."

Player commands

/infinity time set

/infinity time set
Argumenttime: a time of day, the same as /time set. Plain ticks (6000) or with a unit (1d, 30s, 100t).
NeedsThe Time Stone's {{ab time/time_set}} unlocked and the Time Stone active. Without that, nothing happens.
DoesMoves the clock forward to that time of day. If that time has already passed today, it goes to that time tomorrow.
/infinity time set 0
/infinity time set 13000

/infinity soul locateplayer

/infinity soul locateplayer
Argumenttarget: one player, by name or selector.
NeedsThe Soul Stone's {{ab soul/locateplayer_command}} unlocked and the Soul Stone active. Otherwise you get "You are not worthy to use the locate ability."
DoesTells you where that player is, like The entity "Steve" is located at: 120, 64, -48.
/infinity soul locateplayer Pugmeowla

/infinity orb

/infinity orb turn left
/infinity orb turn right
/infinity orb take
/infinity orb insert

These are what the Orb's abilities run, so normally you'd just use the abilities. They only work while you're holding the {{item orb}}. turn moves the combination lock on or resets it, take takes the Power Stone out of an unlocked, open Orb, and insert puts a Power Stone from your inventory back in. See {{page containers.html#orb The Orb}}.

/infinity gauntlet skin

/infinity gauntlet skin set 
/infinity gauntlet skin clear
Argumentskin: a skin ID. It suggests them as you type (like netherite_gauntlet or dragon_gauntlet). See {{page gauntlet/skins.html Gauntlet Skins}}.
TargetThe Infinity Gauntlet in your main hand, otherwise the one you're wearing.
Doesset puts the skin on straight away without using an item. clear takes the skin off and gives you its unlock item.
For server owners

This command doesn't need any permission level, because the skin abilities run it. Since clear gives back the skin's unlock item, you might want to limit it with a permissions mod on a public server.

Admin commands

/infinity gauntlet snap

/infinity gauntlet snap [half|hostile|players|destroy_stones]
TypeWhat it does
(nothing) or halfKills half of the living things in your dimension, chunk by chunk.
hostileSends every #infinity:snap_hostile mob in every dimension to the Snap cell in the Soulworld.
playersSends every other player to the Snap cell.
destroy_stonesEmpties the stones out of your worn gauntlet (or the one in your main hand).

All of them burn you just like a real Snap: half a heart and locked abilities for a Minecraft day. Only one Snap runs at a time. More on {{page gauntlet/snap.html The Snap}}.

/infinity unlock_stones and lock_stones

/infinity unlock_stones
/infinity lock_stones

Unlocks (or locks) every ability of all six stones for you, using Palladium's /ability unlock|lock <player> infinity:<stone> all. It prints "All Infinity Stones Abilities Unlocked!" or "All Infinity Stones Abilities Locked!". For another player or a single stone, use Palladium's command yourself:

/ability unlock Steve infinity:space_stone all
/ability lock Steve infinity:power_stone all

/infinity unlock_orb

/infinity unlock_orb

Unlocks the Orb's combination for you, as if you'd entered it. Prints "The Orb has been unlocked!"

/infinity soulguardian respawn

/infinity soulguardian respawn

Spawns a new Soul Guardian with fresh trades at its spot on Vormir (212 121 99). Works from the console. Prints "The Soul Guardian has returned to Vormir." or "Could not spawn the Soul Guardian." if Vormir isn't there. It doesn't remove a Guardian that's already there.

Useful Palladium commands

The stones are normal Palladium powers, so Palladium's commands work on them. Handy for testing and maps:

# Give or take a stone's power without the item
/superpower add infinity:soul_stone Steve
/superpower remove infinity:soul_stone Steve
