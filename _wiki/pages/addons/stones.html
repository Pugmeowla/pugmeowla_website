How it works

Each item that can go into the Infinity Gauntlet has a file in data/infinity/gauntlet_stones/. The six Infinity Stones are defined this way too. Once an item has a file:

  • It fits in any of the gauntlet's six slots (the same stone can't be in two), in custom gauntlets and in the Cosmi-Rod.
  • Everything is drawn from what's actually in each slot: the gauntlet's inventory icon colors that slot's pixel (textures/item/gauntlet_slots/slot_[n].png), and the worn, held and ground models draw the stone on that slot's socket (geo/gauntlet_slots/slot_[n].geo.json).
  • A stone looks the same everywhere, like 1.12.2: its texture tinted by color, unlit, with two scrolling glint passes in glint_color.
  • Its power is given while it's in any slot of the active gauntlet, and removed as soon as it's taken out.
  • The gauntlet's tooltip lists it as " - Name" in tooltip_color, sorted by tooltip_order.

Fields

KeyDefaultMeaning
itemrequiredThe stone's item. Must be registered; each item can only be one stone.
color#FFFFFF#RRGGBB. Tints the stone texture on the item, in the gauntlet (worn, held, ground, inventory icon), on the head and on the ground, and colors its tooltip line and insert particles.
glinttrueWhether the two scrolling glint passes are drawn.
glint_colorcolor#RRGGBB color of the glint passes.
tooltip_colorcolorColor of the stone's line in the gauntlet tooltip: a chat color name (aqua, light_purple…) or #RRGGBB.
tooltip_order100Position in the tooltip; lower comes first. The six stones use 0–5.
powernonePalladium power given while the stone is in any slot of the active gauntlet (off hand or Curios hands). In a Cosmi-Rod, a stone without power gives the power whose ID equals the item's ID.
headfalseLets the stone be worn in the Curios head slot, drawn on the forehead and giving its power there.
textureinfinity:textures/item/infinity_stone.pngTexture of the stone's cube, tinted by color. Uses the 1.12.2 layout: a 6×6×6 box-UV cube on a 32×16 texture.

Example

Stone definition

{
  "item": "example:chaos_stone",
  "color": "#E0115F",
  "glint_color": "#FF7AA8",
  "tooltip_color": "#E0115F",
  "tooltip_order": 10,
  "power": "example:chaos_stone",
  "head": true
}

Item model

Give the item the stone look in the inventory by using the mod's stone model as its parent:

{
  "parent": "infinity:item/infinity_stone"
}

The real Time Stone

{
  "item": "infinity:time_stone",
  "color": "#13CF55",
  "glint_color": "#12E772",
  "tooltip_color": "green",
  "tooltip_order": 4
}

The six built-in stones have no power field: the gauntlet power gives their powers itself.

Drawing a stone yourself

Palladium render layers can draw any stone with the stone look using the layer type infinity:stone:

{
  "type": "infinity:stone",
  "stone": "example:chaos_stone",
  "model": "example:geo/chaos_stone_socket.geo.json"
}

Checking for a stone

Use the infinity:gauntlet_slot condition (or infinity:gauntlet_slot_mainhand for a held gauntlet) in other powers. See {{page addons/abilities.html#conditions Conditions}}.

{
  "type": "infinity:gauntlet_slot",
  "item": { "item": "example:chaos_stone" }
}

Make it behave like a stone on the ground

Add a {{page addons/ground-items.html ground item}} file with "unique": true so dropped copies can't be duplicated.
