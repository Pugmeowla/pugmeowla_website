Player commands

/infinity time set

/infinity time set <time>
Argumenttime: a time of day, like /time set: ticks (6000) or with a unit (1d, 30s, 100t).
RequiresThe Time Stone's {{ab time/time_set}} unlocked, with the Time Stone active. Without it the command does nothing.
EffectMoves the world's clock forward to that time of day. If it's already later than that today, it skips to that time tomorrow.
/infinity time set 0
/infinity time set 13000

/infinity soul locateplayer

/infinity soul locateplayer <target>
Argumenttarget: one player (name or selector).
RequiresThe Soul Stone's {{ab soul/locateplayer_command}} unlocked, with the Soul Stone active. Otherwise: "You are not worthy to use the locate ability."
EffectTells you where that player is: The entity "Steve" is located at: 120, 64, -48.
/infinity soul locateplayer Pugmeowla

/infinity orb

/infinity orb turn left
/infinity orb turn right
/infinity orb take
/infinity orb insert

These are what the Orb's abilities run; you normally use the abilities instead. They only work while you hold the {{item orb}}. turn advances or resets the combination lock, take takes the Power Stone out of an unlocked, open Orb, and insert puts a Power Stone from your inventory back. See {{page containers.html#orb The Orb}}.

/infinity gauntlet skin

/infinity gauntlet skin set <skin>
/infinity gauntlet skin clear
Argumentskin: a skin ID, suggested as you type (e.g. netherite_gauntlet, dragon_gauntlet). See {{page gauntlet/skins.html Gauntlet Skins}}.
TargetThe Infinity Gauntlet in your main hand, otherwise the one you're wearing.
Effectset applies the skin directly (no item used). clear removes the skin and gives you that skin's unlock item.
For server owners

This command has no permission requirement, because the skin abilities run it. Since clear hands back the skin's unlock item, you may want to limit it with a permissions mod on public servers.

Admin commands

/infinity gauntlet snap

/infinity gauntlet snap [half|hostile|players|destroy_stones]
TypeEffect
(none) or halfKills half of the living entities in your dimension, chunk by chunk.
hostileSends every #infinity:snap_hostile mob in every dimension to the Soulworld Snap cell.
playersSends every other player to the Soulworld Snap cell.
destroy_stonesEmpties the stones out of your worn gauntlet (or the one in your main hand).

Every type burns you exactly like a real Snap: half a heart of health and locked abilities for a Minecraft day. Only one snap runs at a time. Details: {{page gauntlet/snap.html The Snap}}.

/infinity unlock_stones and lock_stones

/infinity unlock_stones
/infinity lock_stones

Unlocks (or locks) every ability of all six stone powers for you, using Palladium's /ability unlock|lock <player> infinity:<stone> all. Prints "All Infinity Stones Abilities Unlocked!" or "…Locked!". To do it for another player or a single stone, use Palladium's command directly:

/ability unlock Steve infinity:space_stone all
/ability lock Steve infinity:power_stone all

/infinity unlock_orb

/infinity unlock_orb

Unlocks the Orb's combination lock for you, as if you'd entered the full combination. Prints "The Orb has been unlocked!"

/infinity soulguardian respawn

/infinity soulguardian respawn

Spawns a new Soul Guardian, with fresh trades, at its spot on Vormir (212 121 99). Can be run from the console. Prints "The Soul Guardian has returned to Vormir." or "Could not spawn the Soul Guardian." if Vormir isn't available. It doesn't remove an existing Guardian.

Useful Palladium commands

Stones are ordinary Palladium powers, so Palladium's own commands work on them, which helps for testing and maps:

# Give or take a stone's power without the item
/superpower add infinity:soul_stone Steve
/superpower remove infinity:soul_stone Steve
