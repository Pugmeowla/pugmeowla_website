What it does

Infinity Stone Core themes Palladium's skill tree (the powers screen) in place. There's no new menu: Palladium's own textures are tinted, so the layout, scrolling, tabs, tooltips, unlocking and buying all work exactly as before.

The Infinity Stones are drawn in their stone's color from data/infinity/gauntlet_stones: Power purple, Space blue, Reality red, Soul orange, Time green and Mind yellow. A custom stone gets its own color too. That covers:

  • the ability frames, bright when unlocked and dim when locked
  • the title bar and description box you see when hovering an ability
  • the power's tab, brighter while it's open
  • the lines between abilities

The Power, Space, Mind and Soul Stones' trees and the Infinity Gauntlet's also have their own background and window art.

Anything else, any power or single ability from any mod, can be themed by a JSON file in assets/<namespace>/ability_overlays/ of a resource pack, a mod or an addon pack. Files reload with resources (F3 + T), with no restart and no Java. A power or ability with neither a stone nor a file is drawn exactly as Palladium draws it.

Settings

Everything is optional except the target. Colors are #RRGGBB, or #RRGGBBAA for transparency, and tint (multiply) what Palladium draws.

ability

Meaning
Target: one ability, as power#ability. Palladium's addon pack dev mode shows it in the ability's description.

power

Meaning
Target: a power, meaning its tab, its lines and all its abilities.

accent_color

Default
the stone's color, else white
Meaning
The theme's color. Every color you leave out is worked out from it.

frame_color

Default
accent, lightened
Meaning
Frame of an unlocked ability.

locked_color

Default
accent, dimmed
Meaning
Frame of a locked ability.

hover_color

Default
accent, lightened
Meaning
Title bar shown while the ability is hovered.

background_color

Default
accent, faint
Meaning
The hovered ability's description box. Alpha makes it see-through.

title_color

Default
white
Meaning
The hovered ability's name.

description_color

Default
light grey with a touch of accent
Meaning
The hovered ability's description.

tab_color

Default
accent, light
Meaning
Power only: the power's tab.

selected_tab_color

Default
accent, stronger
Meaning
Power only: the tab while it's open.

line_color

Default
accent
Meaning
Power only: lines to unlocked abilities.

locked_line_color

Default
accent, dark
Meaning
Power only: lines to locked abilities.

frame_texture

Default
Palladium's frame, tinted
Meaning
26×26 texture (the whole file) drawn as the unlocked frame, untinted.

locked_frame_texture

Default
Palladium's frame, tinted
Meaning
26×26 texture drawn as the locked frame, untinted.

background_texture

Default
the power's tiled background
Meaning
Power only: an image drawn behind the abilities instead. It doesn't scroll.

window_textures

Default
the stone's window art, if any
Meaning
Power only: images drawn over Palladium's window, in order. They're never darkened while an ability is hovered.

icon

Default
the ability's own icon
Meaning
16×16 texture (the whole file) drawn as its icon in the skill tree. Locked abilities still show the padlock.

locked_icon

Default
the padlock
Meaning
16×16 texture drawn instead of the padlock while the ability is locked. Meant for abilities bought for 0 levels that lock themselves again as a switch. The stones' toggles use infinity:textures/icon/toggle.png.

background_texture and window_textures are drawn whole at 1:1, centred on Palladium's 252×196 window. So an image with the window drawn in its middle, on a canvas of any size, lines up by itself. The Power Stone's file uses 512×256 images with the frame at 130, 30 and the side art on the same canvas:

{
  "power": "infinity:power_stone",
  "background_texture": "infinity:textures/gui/powers/power_stone_background.png",
  "window_textures": [
    "infinity:textures/gui/powers/power_stone_details.png",
    "infinity:textures/gui/powers/power_stone_frame.png"
  ]
}

How settings combine

  • An ability's settings come from its own file, then its power's file, then the stone's color. Anything still missing is worked out from the accent, so a file only has to name what it changes.
  • A file at the same path in a higher resource or addon pack replaces a lower one, like any resource.
  • Where different files theme the same target, the one whose ID sorts last wins for each setting it sets.
  • An invalid color or a texture that doesn't exist is logged (Ability overlay <file>: ...) and left out, so its default is used. A file without a valid ability or power is skipped. Nothing here can crash the game.

Examples

From the test pack

The Test Stone's Clones ability in turquoise, with the Mind Stone's illusion icon. The rest of the Test Stone stays pink.

{
  "ability": "infinity_test_stone:test_stone#illusions",
  "accent_color": "#40E0D0",
  "background_color": "#9FEDE6E6",
  "locked_color": "#3A5A57",
  "icon": "infinity:textures/icon/illusion.png"
}

Accent only

The frame, hover bar, description box and text all follow the new accent.

{
  "ability": "infinity_test_stone:test_stone#illusions",
  "accent_color": "#40E0D0"
}

Custom frame

Your mod or addon pack ships these textures at assets/infinity_test_stone/textures/gui/....

{
  "ability": "infinity_test_stone:test_stone#illusions",
  "frame_texture": "infinity_test_stone:textures/gui/illusions_frame.png",
  "locked_frame_texture": "infinity_test_stone:textures/gui/illusions_frame_locked.png",
  "icon": "infinity_test_stone:textures/gui/illusions_icon.png"
}

Every state

The open ("selected") look belongs to a power's tab: set tab_color and selected_tab_color in a power file.

{
  "ability": "infinity_test_stone:test_stone#illusions",
  "frame_color": "#A8E6FF",
  "locked_color": "#3B4A55",
  "hover_color": "#C9F1FF",
  "background_color": "#10233ACC",
  "title_color": "#FFFFFF",
  "description_color": "#B5D9EA"
}

Re-theme a stone ability

In a resource pack. The Space Stone's other abilities, tab and lines stay blue.

{
  "ability": "infinity:space_stone#teleport",
  "accent_color": "#B388FF"
}

A whole power

From an addon pack, the file goes in addonpacks/<pack>/assets/<namespace>/ability_overlays/.

{
  "power": "infinity_test_stone:test_stone",
  "accent_color": "#FF69B4",
  "selected_tab_color": "#FFC2E2"
}
