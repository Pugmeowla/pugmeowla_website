Using them

All of these work in any Palladium power file (data/<namespace>/palladium/powers/*.json) like Palladium's own types. Properties left out use the defaults listed here. This is part of the Test Stone's power from the {{page addons/index.html#addon-pack test pack}}: a power level on its own energy bar, an energy blast that scales with it, and a Sling Ring portal in the fire style.

{
  "name": "Test Stone",
  "icon": "infinity_test_stone:test_stone",
  "background": "minecraft:textures/block/pink_concrete.png",
  "gui_display_type": "tree",
  "energy_bars": {
    "level": {
      "color": "#FF69B4",
      "max": 5,
      "min": 0,
      "synced_value": { "type": "score", "objective": "TestStoneLevel", "fallback": 0 }
    }
  },
  "abilities": {
    "level": {
      "type": "infinity:power_level",
      "title": "Power Level",
      "description": "Level 0-5 shown on the level bar. Damage abilities below scale with it.",
      "hidden_in_bar": true,
      "hidden": true,
      "objective": "TestStoneLevel",
      "max_level": 5
    },
    "level_up": {
      "type": "infinity:power_level_change",
      "title": "Level Up",
      "description": "Raises the power level.",
      "bar_color": "pink",
      "gui_position": [0, 1],
      "amount": 1,
      "conditions": {
        "enabling": [ { "type": "palladium:action", "cooldown": 0 } ]
      }
    },
    "blast": {
      "type": "infinity:energy_blast",
      "title": "Energy Blast",
      "description": "Fires a pink blast whose damage doubles with each level.",
      "bar_color": "pink",
      "gui_position": [2, 1],
      "damage": 6.0,
      "color": "#FF69B4",
      "scale_with_power_level": true,
      "conditions": {
        "enabling": [ { "type": "palladium:action", "cooldown": 10 } ]
      }
    },
    "sling_ring": {
      "type": "infinity:portal",
      "title": "Sling Ring",
      "description": "Opens the portal menu and travels through a ring of sparks, like Doctor Strange.",
      "bar_color": "orange",
      "gui_position": [5, 2],
      "style": "fire",
      "conditions": {
        "enabling": [ { "type": "palladium:action", "cooldown": 40 } ]
      }
    }
  }
}

The full file in the test pack uses nearly every ability type on this page. To lock an ability until the stone is in a gauntlet, add "unlocking": [ { "type": "infinity:gauntlet_slot", "item": { "item": "infinity_test_stone:test_stone" } } ] to its conditions.

Palladium's generated documentation (mods/documentation/) lists the same types with the exact property formats for your installed version.
